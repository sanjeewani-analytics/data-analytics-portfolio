# Project 003 – Warehouse Inventory Risk Analysis & Executive Dashboard

## Business Scenario

A fictional organisation requested an analysis of warehouse inventory to evaluate inventory value, reorder status, supplier distribution, lead-time risks, and inventory criticality. The objective was to identify operational risks and provide practical recommendations to improve inventory management and business continuity.

---

## Project Objectives

- Assess inventory data quality
- Clean and validate datasets
- Integrate multiple datasets using XLOOKUP
- Analyse inventory value
- Evaluate reorder levels
- Assess supplier distribution
- Perform lead-time risk analysis
- Build an executive dashboard
- Present business recommendations
